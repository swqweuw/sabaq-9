==============================================================
  УРОК 4 · Flask · ЗАДАНИЕ «Найди и исправь ошибки»
==============================================================

Перед вами «Электронный дневник» на Flask. Сайт запускается,
страницы открываются, ничего не «падает» — но в нём спрятано
3 ОШИБКИ: в некоторых случаях он показывает неправильные данные.
Регистрация, вход и выход работают правильно.

Найдите все 3 ошибки и исправьте их.


КАК ДОЛЖЕН РАБОТАТЬ ДНЕВНИК
  1. После входа открывается страница «Оценки»: таблица
     предметов, оценки по каждому, средний балл и итог за
     четверть.
  2. Оценку можно поставить формой над таблицей. Сразу после
     этого в строке предмета меняются оценки, средний балл
     и итог.
  3. Средний балл — среднее арифметическое оценок
     (две цифры после запятой).
  4. Итог за четверть — средний балл, округлённый по школьным
     правилам: дробная часть 0,5 и больше — вверх, меньше 0,5 —
     вниз. Например: 4,50 -> 5; 4,49 -> 4; 3,50 -> 4; 2,50 -> 3.
  5. У каждого пользователя свои оценки, свой средний балл
     и свой итог. Другие пользователи их не видят.
  6. На странице «Домашние задания» можно добавить задание
     со сроком сдачи. Задания отсортированы по сроку сдачи:
     сначала те, которые сдавать раньше. Выполненные — в конце.
  7. Статус задания: «Просрочено» — срок уже прошёл;
     «Сдать сегодня» — срок сегодня; «Осталось дней: N» —
     срок ещё не наступил; «Выполнено» — нажата кнопка «Готово».


КАК ЗАПУСТИТЬ
  1. Откройте эту папку в терминале (или в VS Code / PyCharm).
  2. Установите Flask:      pip install -r requirements.txt
  3. Запустите сайт:        python app.py
  4. Откройте в браузере:   http://127.0.0.1:5000


ЧТО СДАТЬ
  - исправленный файл app.py;
  - для каждой ошибки напишите:
      • в какой строке она была;
      • в каком случае сайт работал неправильно (пример);
      • почему так происходило и как вы её исправили.


ПОДСКАЗКИ
  - Проверяйте каждый пункт списка выше на РАЗНЫХ данных:
    разные оценки, разные даты, несколько пользователей.
  - Ошибка может проявляться не всегда, а только в
    определённых случаях.
  - Чтобы начать с чистой базы: остановите сайт (Ctrl+C),
    удалите файл dnevnik.db и снова запустите python app.py.
